# Lyrical-Homie – Benchmark

This repository contains an evaluation framework designed to measure the performance of my RAG engine.

## Evaluation Metrics

A sample query is located in the `datasets/benchmark_dataset_sample.json` file. The program measures the accuracy of many similar queries generated by `llama-3.3-70b-versatile` in the `query_generator.py` script.
The benchmark includes three evaluation metrics.

### 1. Intent Accuracy
Measures if the **Gatekeeper (Classifier)** correctly identifies the user's intention.
* **Categories:** `GREETING`, `SITUATION`, `QUESTION`, `BRAGGA` (I decide do not include `SEARCH_TOPIC` category in this particular test.)
* **Goal:** Ensure the system understands the context before searching the database.

### 2. Retrieval: Strict Hit Rate (ID Match)
The "Sniper" metric. It checks if the specific chunk ID from the dataset is present in the `top_candidates`.
* **Success condition:** `expected_id == predicted_id`.
* **What it tests:** The absolute precision of my embedding model and the effectiveness of `HyDE` process.

### 3. Retrieval: Soft Hit Rate (Context Match)
It checks if the expected lyrics appear anywhere within the **Parent Context** of the retrieved chunks. Even if the vector search didn’t find that exact line, perhaps it is included in the context?
* **Success condition:** `expected_text` is found within the retrieved `parent_text`.
* **What it tests:** Real-world utility. This reflects what the user can actually see.

* `datasets/`: Contains genrated datasets
